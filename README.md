# Cell: Multiverse Absorption

Un piccolo gioco browser in cui Cell si muove tra i mondi del multiverso e assorbe le protagoniste delle dimensioni rivali per crescere sempre più forte.

## Come giocare

- Apri `index.html` nel browser
- Muovi Cell con `WASD` o le frecce
- Cerca di assorbire i nemici per crescere
- Evita di essere colpito troppo spesso
- Premi `R` per riavviare

## Obiettivo

- Aumentare il punteggio
- Evolvere Cell
- Dominare le dimensioni del multiverso

## Struttura

- `index.html` = schermata di gioco
- `style.css` = interfaccia grafica
- `script.js` = logica di gameplay

## Nota

Il gioco è progettato come prototype semplice e giocabile, pronto per essere esteso con suoni, menu, livelli e boss finali.
